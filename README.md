# GoodFood Food Ordering Website

GoodFood is a responsive food ordering website developed using HTML, CSS, and JavaScript. It simulates a real-world restaurant ordering experience.

## Features

* Interactive food menu
* Category-based filtering
* Add-to-cart functionality
* Dynamic order summary
* QR code payment integration
* Receipt generation and printing
* Dark mode support
* Responsive design

## Tech Stack

* HTML
* CSS
* JavaScript

## Website Sections

* Landing Page
* Menu Section
* Order Management
* Cart System
* Payment Section
* Receipt Generation

## Project Goal

The project was created to demonstrate a complete food ordering workflow with a modern and user-friendly interface.
